# 出題規格（AI 學生的前後測）

這份是給「出題者」看的。出題者**只看 `input/case_input.json`**（和原片片段），**不看要評的影片**。
試題在看影片之前定下來並凍結，才量得到「這支影片讓學生學會了什麼」，而不是「影片講了什麼就考什麼」。

## 先寫學習目標

從學生的問題、`learner_profile.misconception`、`known_concepts`、`context_summary` 推出 **2–4 個學習目標**，
寫成「看完之後，學生能 ＿＿」：

- 目標要能從學生的問題直接推出來，不寫延伸內容。
- 至少一個目標直接對應迷思：「能說出 ＿＿ 不是判斷依據，真正的依據是 ＿＿」。

## 題目藍圖

6–12 題。每題標一個 `role`、一個 `objective`：

| role | 量什麼 | 至少 | 說明 |
|---|---|---|---|
| `target` | 學生原本的問題 | 2 | 把問題換句話問；問題有兩個部分就各出一題 |
| `diagnostic` | 迷思有沒有被修正 | 2 | 選擇題，錯誤選項裡要有一個**正好是迷思會選的**（寫進 `misconception_option`）；或是非題，敘述就是迷思本身 |
| `near` | 近遷移 | 1 | 同一個判準，換一個沒出現在原片和問題裡的例子 |
| `far` | 遠遷移 | 1 | 要用判準推理一步才答得出來的新情境 |
| `control` | 控制題 | 1 | **這支補充影片不會教、而且學生前測應該答錯**的概念：例如同一單元原片提問時間**之後**才教的點，或同一科高一個年段的概念。要避開學生問題和迷思裡出現的名詞與部位。看完前後應該維持答錯；如果 AI 學生看完突然答對，就代表他沒守住角色、用了自己的知識。`objective` 填 `"control"` |

## 題型

只用能自動判分的題型，避免判分本身又帶進一層主觀：

| type | 欄位 | 判分 |
|---|---|---|
| `mcq` | `options`（3–5 個，A–E）、`key`、`misconception_option`（diagnostic 必填） | 選項相同 |
| `tf` | `key`（true／false） | 相同 |
| `numeric` | `key`、`tolerance`（預設 0）、`unit`（選填） | 差距在容許範圍內 |
| `short` | `accept`（可接受答案清單，2–6 字的關鍵詞） | 正規化後與任一個完全相同（學生只能填關鍵詞，不寫句子）。能用選擇或是非題就不要用簡答 |

`numeric` 的 `key` 只能是一個數字（整數或小數）；分數答案請改用選擇題。

## 寫題的規則

1. 題幹用該年段讀得懂的話，一題只問一件事。
2. 錯誤選項要「有人會選」：來自迷思、常見錯誤、或只學一半的人會犯的錯。不要放明顯荒謬的選項。
3. 不要讓題目互相洩答案（後一題的題幹不能透露前一題的答案）。
4. 選擇題的正確答案位置要分散，不要都是 B。
5. 每題（控制題除外）寫 `evidence_keywords`：2–5 個詞，是「一支有教到這題的補充影片，講解時一定會說到的詞」（例如蜘蛛題寫「蜘蛛」「頭胸部」）。學生後測引用影片原句時，引文附近要出現其中一個詞，才算這題真的有影片依據。不要放題目本身的選項答案詞（例如「三段」這種所有題目都會講到的詞就太泛），要放能區分「影片有沒有講到這一題」的詞。
6. 每題寫 `rationale`：為什麼這是正確答案、每個錯誤選項代表哪一種想法。這段**不會**給學生看。
7. 不用提問時間之後的內容出題（控制題除外）。答案要能從「原片到提問時間為止的內容＋一支好的補充說明該講的東西」推得；`misconception` 欄位明白點到的判準（例如「三對腳」）可以考，其他課本知識不要考。

## 檔案格式：`eval/items.json`

```json
{
  "case_id": "V01",
  "written_by": "出題者的名字或模型",
  "objectives": [
    {"id": "O1", "text": "能用「頭、胸、腹三段」判斷螞蟻是不是昆蟲"},
    {"id": "O2", "text": "能說出「體型小、會爬」不是判斷昆蟲的依據"}
  ],
  "items": [
    {"id": "Q1", "role": "target", "objective": "O1", "type": "mcq",
     "stem": "螞蟻的身體分成幾段？",
     "options": {"A": "兩段", "B": "三段", "C": "四段"},
     "key": "B", "misconception_option": "A", "evidence_keywords": ["螞蟻", "腰", "胸和腹"],
     "rationale": "胸和腹之間的腰很細，看起來像兩段（A），其實是頭、胸、腹三段。"}
  ]
}
```

寫好後執行 `python3 SKILL/scripts/score.py freeze`，它會檢查藍圖，並把試題鎖起來（記下雜湊值）。
之後同一題重評（例如老師改了影片）**沿用同一份試題**，分數才能比較；要檢查是不是「針對考題調整」，另出一份平行試題（見 `instrument/README.md`〈複本〉）。
