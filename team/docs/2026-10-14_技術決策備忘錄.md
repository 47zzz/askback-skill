## 1. 本地 voice-clone TTS 的選擇

### 結論先講
截至 2026-10-14，**沒有任何一個開放模型被證實在「臺灣國語 + 繁體 + 多音字控制」這條軸上優於 BreezyVoice**。新模型（CosyVoice3、Qwen3-TTS、GLM-TTS、VoxCPM2、IndexTTS）的 CER/SIM 優勢全部來自 Seed-TTS test-zh（簡體、中國大陸語者）的自評數字，沒有任何 zh-TW 評測，也找不到任何「複製臺灣語者」的第一手回報（TTS 研究報告 notes；zh-TW 報告 (b)）。因此採 **「首選維持 BreezyVoice、備援引入 Fun-CosyVoice3、以 A/B 評測決定是否切換」** 的策略，而不是直接換引擎。

### 首選：BreezyVoice-300M（MediaTek Research）— 維持現狀，但補強
- **理由**：唯一明確針對臺灣國語訓練的開放 TTS；原生吃繁體；行內注音覆寫 `今天天氣真好[:ㄏㄠ3]`；內建 G2PW 自動標注多音字（<500 頻字 / 讀音異於常見讀音者）；論文 TCMD PER 0.80%、SSL-MOS 4.46、SIM 92.29%（https://github.com/mtkresearch/BreezyVoice ；https://arxiv.org/abs/2501.17790 ；https://raw.githubusercontent.com/mtkresearch/BreezyVoice/main/single_inference.py）。
- **License**：Apache-2.0（GitHub + HF）。範例音檔 tc_speaker.wav 商用疑問 #15 無人回覆 → 只用自己的參考音檔（https://github.com/mtkresearch/BreezyVoice/issues/15）。
- **VRAM**：官方未列；CosyVoice-1 等級模型，估 <6 GB（UNVERIFIED）。issue #10 顯示 CPU 結果劣於 GPU → 一律在 3090 上跑（https://github.com/mtkresearch/BreezyVoice/issues/10）。
- **安裝 pins（HEAD 仍是 d592c9d，2025-06-21，16 個月無程式碼變更，故姊妹專案的 pin 依然有效）**：Python 3.10；`torch==2.3.1 torchaudio==2.3.1`（cu118 index）；`onnxruntime-gpu==1.16.0`；`openai-whisper==20231117`；`WeTextProcessing==1.0.3`；`deepspeed==0.14.2`；`diffusers==0.32.0`；g2pw、opencc-python-reimplemented 未釘版；ttsfrd 0.3.9 cp310 wheel；需 `PYTHONUTF8=1`（https://raw.githubusercontent.com/mtkresearch/BreezyVoice/main/requirements.txt ；https://api.github.com/repos/mtkresearch/BreezyVoice/commits?per_page=5）。
- **繁體與多音字**：繁體直接輸入；多音字由 G2PW 自動標 + 每課 override 表手動補 `字[:ㄓㄨㄥ4]`（長/行/樂/重/和/數）。注意：繼承的 WeTextProcessing 1.0.3 `Normalizer` master 預設 `traditional_to_simple=True`，BreezyVoice 是否整句轉簡 **UNVERIFIED**（https://raw.githubusercontent.com/wenet-e2e/WeTextProcessing/master/tn/chinese/normalizer.py）。數字與算式（「1598-260」）一律在送進任何引擎前自行以繁體 verbalize。
- **參考音檔**：16 kHz mono（`load_wav(path,16000)`），繼承 CosyVoice ≤30 s assert（對此 fork UNVERIFIED），建議 6–15 s、乾淨單人、無 BGM；一定要給 transcript，不要讓它用 whisper-base 自動轉（zh-TW 很弱）。
- **缺點（為何還要備援）**：2025-06 起停更；CosyVoice-1 架構，相似度理論上低於 CosyVoice2/3 血統（推論，UNVERIFIED）；無 CER/SIM 公開數字；無 speaker cache（#8/#12）；torch 2.3.1 cu118 舊 stack。MediaTek 2026 的「BreezyVoice 26」是台語 TTS、權重未釋出，官方部落格明說無國語 TTS 更新（https://www.mediatek.com/zh-tw/tek-talk-blogs/mediatek-research-breeze-3 ；https://github.com/mtkresearch/BreezyVoice/issues/14 ；https://arxiv.org/abs/2603.19259）。

### 備援（A/B 候選）：Fun-CosyVoice3-0.5B-2512 + `llm.rl.pt`
- **正確識別碼**：HF 只有 `FunAudioLLM/Fun-CosyVoice3-0.5B-2512` 一個 repo；「_RL」不是獨立模型，RL 權重是同 repo 內的 `llm.rl.pt`，載入需把它改名/symlink 成 `llm.pt`（維護者 #1780）（https://huggingface.co/FunAudioLLM/Fun-CosyVoice3-0.5B-2512/tree/main ；https://github.com/QwenAudio/CosyVoice/issues/1780）。GitHub 已 301 到 QwenAudio/CosyVoice。
- **理由**：Apache-2.0（程式與權重）；test-zh CER 1.21→0.81（RL），但 SIM 78.0→77.4 略降；拼音 inpainting 可覆寫多音字；社群在 3090 實測 ~5.2 GB VRAM（二手，fengin）；fp32 eager 每句 ~4–8 s（推估自 3090 Ti 數據，UNVERIFIED）（https://github.com/FunAudioLLM/CosyVoice ；https://github.com/fengin/Fun-CosyVoice3-0.5B-2512-Deploy ；https://github.com/instavar/cosyvoice3-lora-finetuning）。
- **安裝 pins（與 BreezyVoice 不能共用 venv：cu121 vs cu118）**：Python 3.10；`torch==2.3.1 torchaudio==2.3.1`（`--extra-index-url .../cu121`）；**`transformers==4.51.3` 硬性**（≥4.53 會讓輸出變成流暢胡言，#1446/#1953 仍 open）；`onnxruntime-gpu==1.18.0`；`numpy==1.26.4`；`--recursive` 拉 Matcha-TTS；不要在同環境裝 vLLM（會偷升 torch，#1847）（https://raw.githubusercontent.com/QwenAudio/CosyVoice/main/requirements.txt ；https://github.com/QwenAudio/CosyVoice/issues/1953 ；https://github.com/QwenAudio/CosyVoice/issues/1847）。
- **必備護欄（來自大量 issue）**：`prompt_text` 必加前綴 `You are a helpful assistant.<|endofprompt|>`（#1735/#1761）；`fp16=False`、不用 TRT fp16（#1930 NaN）；參考音檔 24 kHz mono 5–15 s、transcript 逐字吻合（#1762）；一句一 call、避免「？」（#1704）；best-of-N≥3 + Whisper CER + 時長/字數比檢查（抓重複與吞尾字 #1902/#1730）+ 去頭尾靜音與 fade（#1786）（https://github.com/QwenAudio/CosyVoice/issues/1703 ；https://github.com/QwenAudio/CosyVoice/issues/1704 ；https://github.com/QwenAudio/CosyVoice/issues/1730 ；https://github.com/QwenAudio/CosyVoice/issues/1930）。
- **繁體**：**會念錯**，不是「沒處理」而已——#1764 鈴鐺/蝦/胡蘿蔔 念錯，轉簡體後正常 → `tts_text` 與 `prompt_text` 都必須 OpenCC **t2s**（純字形，不要 tw2sp 換詞）（https://github.com/QwenAudio/CosyVoice/issues/1764 ；https://github.com/BYVoid/OpenCC）。臺灣讀音（和 hàn、垃圾 lèsè）預期會是大陸讀音，需靠拼音覆寫。
- **多音字語法與 BreezyVoice 不是 1:1**：BreezyVoice 是字後綴 `[:ㄏㄠ3]`；CosyVoice3 是「用聲母 token + 帶調號韻母 token 取代該字」`報道[j][ǐ]予`，token 清單固定於 `CosyVoice3Tokenizer.additional_special_tokens`。需寫 注音→(聲母, 韻母+調號) 轉換表，處理零聲母/ü/iu/ui/輕聲；部分韻母 token 是否齊全 UNVERIFIED（https://raw.githubusercontent.com/FunAudioLLM/CosyVoice/main/cosyvoice/tokenizer/tokenizer.py ；https://raw.githubusercontent.com/FunAudioLLM/CosyVoice/main/example.py）。
- **參考音檔硬限制**：`assert speech.shape[1]/16000 <= 30`（https://raw.githubusercontent.com/FunAudioLLM/CosyVoice/main/cosyvoice/cli/frontend.py）。
- **臺灣腔**：方言表有 Minnan 但那是閩南語非臺灣國語；臺灣腔只能靭參考音檔零樣本帶出，強度 UNVERIFIED。採用門檻：若 2–3 位均一老師音檔的重試率 >~30% 或口音明顯大陸化 → 不切換。

### 第三候選（僅內部評測，不預設開放）：IndexTTS-2（2.0 checkpoint）
- 音色/情感被多數社群評為最強，但：拼音覆寫只在 `pinyin.vocab` 內有效且常被忽略（#625/#669/#686/#792）；短句吞字/多餘靜音 17 個月未修（#187/#58/#617）；2.5 有中文品質回退（#801/#759 無維護者回覆）；2.0 **沒有** duration control（README 明言 not yet enabled）；6 GB VRAM 數字是 2.5 的。License 為 bilibili 自訂：中文版門檻是年收 **1 億**人民幣（英文版寫 10 億，中文版優先）、PRC 法律、輸出算 Derivative Work，且 DISCLAIMER 禁止「未經授權將合成聲音用於商業目的」→ 複製均一老師聲音需取得老師/均一授權。PR #590（繁體自動轉簡）被關閉未合併，作者註明「簡體輸入明顯較好」（https://github.com/index-tts/index-tts ；https://raw.githubusercontent.com/index-tts/index-tts/main/LICENSE_ZH.txt ；https://raw.githubusercontent.com/index-tts/index-tts/main/DISCLAIMER ；https://github.com/index-tts/index-tts/issues/801 ；https://github.com/index-tts/index-tts/issues/625 ；https://github.com/index-tts/index-tts/pull/590）。

### 不採用（附一句理由）
- **Qwen3-TTS-1.7B-Base**：Apache、pip 即裝、真 list-batch，但零發音控制（#99/#273 無人回）；#341 參考音檔尾巴會漏到輸出開頭；串流模式語速漂移（#239，需 `non_streaming_mode=True`）；3090 實測 RTF ~3（HF disc #18）；zh-TW 工具回報繁體輸入被念成粵語腔（Augur ADR-005）；repo 自 2026-03-17 停更，issue 由 bot 關閉；且 CER 0.77 並非最低（同表 CosyVoice3 0.71）（https://github.com/QwenLM/Qwen3-TTS ；https://github.com/QwenLM/Qwen3-TTS/issues/341 ；https://raw.githubusercontent.com/astroicers/Augur/main/docs/adr/ADR-005-optional-external-tts.md ；https://huggingface.co/Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice/discussions/18）。
- **GLM-TTS**：RL 權重**未釋出**（README 仍 Coming Soon、#23 維護者確認、#29 open），實際只有 base CER 1.03；flag 是 `--use_phoneme` 非 `--phoneme`，且開啟後韻律卡頓（#35/#36 維護者承認）；fp32 必須；開頭嗶聲 #55 無人回（https://github.com/zai-org/GLM-TTS ；https://github.com/zai-org/GLM-TTS/issues/23 ；https://github.com/zai-org/GLM-TTS/issues/36 ；https://github.com/zai-org/GLM-TTS/issues/55）。
- **VoxCPM2**：Apache、SIM 79.5 最高、內建 denoiser 與 `voxcpm batch`，但無任何發音覆寫 → 多音字無解；可列為 bake-off 第 4 名（https://github.com/OpenBMB/VoxCPM）。
- **GPT-SoVITS**：MIT、極活躍（V5 2026-10-05）、G2PW 自動多音字、zh_normalization 內建繁→簡與算式唸法，但安裝最重、無使用者拼音覆寫（PR #1728 未合併）；唯一優勢是同一老師可用 1 分鐘微調，若未來「固定老師」場景出現再評估（https://github.com/RVC-Boss/GPT-SoVITS ；https://github.com/RVC-Boss/GPT-SoVITS/pull/1728）。
- **F5-TTS / OmniVoice / Fish / Chatterbox / Spark / MegaTTS3 / MOSS-TTS / Step-Audio-EditX**：分別因 CC-BY-NC 權重、中文品質差（#287）、停更、WaveVAE encoder 未釋出、8B 太重 / torch 2.9.1 stack 等排除（來源見研究報告）。

### 跨引擎共用的前端（不管哪個引擎都要）
1. 數字/單位/算式 → 繁體中文字（借 GPT-SoVITS `zh_normalization` 的規則順序：RE_ASMD/分數/百分比/小數，`+−×÷=`→加減乘除等）（https://raw.githubusercontent.com/RVC-Boss/GPT-SoVITS/main/GPT_SoVITS/text/zh_normalization/text_normlization.py）。
2. `g2pw`（預設繁體、注音輸出）當共用多音字 oracle，lesson.json 可帶每詞讀音；再依引擎輸出 `[:ㄏㄠ3]` 或 `[j][ǐ]`（https://github.com/GitYCC/g2pW）。
3. 非 BreezyVoice 引擎：OpenCC t2s 後才送入；字幕維持繁體。
4. best-of-N by CER：裁判 ASR 必須與 TTS 訓練資料獨立（見第 2 節 A8 偏誤）。

## 2. GPU 前處理流程（prefix.mp4 → 參考音檔 + 文字稿 + 說話者輪廓）

### 環境（三個獨立 venv；階段間以 work/ 內的 WAV/JSON 溝通）
```bash
# venv-asr：VAD + ASR + speaker embedding + 輪廓 + CER 裁判（CUDA 12 全靠 pip wheel，不需 root）
uv venv ~/.askback/venv-asr --python 3.11 && source ~/.askback/venv-asr/bin/activate
pip install "faster-whisper==1.2.1" "ctranslate2==4.8.2" nvidia-cublas-cu12 "nvidia-cudnn-cu12==9.*"   # 4.8.3 才 1 天新，釘 4.8.2
pip install "silero-vad==6.2.3" torch torchaudio "praat-parselmouth==0.4.7" "jiwer==4.0.0" opencc "speechbrain==1.1.1" scikit-learn numpy soundfile
export LD_LIBRARY_PATH="$(python -c 'import os,nvidia.cublas.lib,nvidia.cudnn.lib;print(os.path.dirname(nvidia.cublas.lib.__file__)+":"+os.path.dirname(nvidia.cudnn.lib.__file__))')${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"   # 必須在 python 啟動前設定

# venv-sep：音樂分離 + 降噪（48 kHz）
uv venv ~/.askback/venv-sep --python 3.11 && source ~/.askback/venv-sep/bin/activate
pip install "demucs==4.1.0" deepfilternet        # 選配：pip install clearvoice（MossFormer2_SE_48K）

# venv-tts：BreezyVoice（py3.10, torch 2.3.1 cu118, d592c9d）不動；venv-tts-cv3：CosyVoice3（py3.10, torch 2.3.1 cu121, transformers 4.51.3）
```
來源：https://github.com/SYSTRAN/faster-whisper ；https://pypi.org/project/ctranslate2/#history ；https://pypi.org/project/silero-vad/ ；https://github.com/adefossez/demucs ；https://github.com/Rikorose/DeepFilterNet ；https://pypi.org/project/speechbrain/

一次性模型暖機（需網路一次，不需 token）後設 `HF_HUB_OFFLINE=1`：faster-whisper `large-v3` 與 `SoybeanMilk/faster-whisper-Breeze-ASR-25`、demucs htdemucs、DeepFilterNet3、`speechbrain/spkrec-ecapa-voxceleb`。

### 步驟（嚴格順序；前處理階段一次只駐留一個模型，每階段獨立 process）
| # | 步驤 | 工具 / 指令 | VRAM | 備註 |
|---|---|---|---|---|
| 1 | 抽音訊 | `ffmpeg -i prefix.mp4 -vn -ac 1 -ar 48000 -c:a pcm_s16le work/a48.wav`；再 soxr 轉 16 k | 0 | 保 48 k 母帶 + 16 k 工作檔 |
| 2 | 音樂判定 + 人聲分離 | `demucs -n htdemucs --two-stems=vocals --segment 8 -o work/demucs work/a48.wav` | ~3 GB（不加 `--segment 8` 約 7 GB） | 一律跑，但只在 no_vocals RMS 高於 mix−30 dB 時才**使用** stem（Demucs 有相位/頻譜拖尾，無 BGM 時不要付這代價）；殘留音樂才換 `htdemucs_ft`（https://github.com/adefossez/demucs ；https://arxiv.org/pdf/2603.16805） |
| 3 | 保守降噪 | `deepFilter in.wav --output-dir work/dfn`（DEFAULT_MODEL=DeepFilterNet3，非生成式） | <1 GB（UNVERIFIED） | 門控：raw vs enhanced 的 speaker-embedding cosine ≥0.85 **且** raw SNR 差才採用。**不用** resemble-enhance（生成式、URGENT-2025 指出會幻覺）與 facebookresearch/denoiser（archived、CC-BY-NC）（https://raw.githubusercontent.com/Rikorose/DeepFilterNet/main/DeepFilterNet/df/enhance.py ；https://arxiv.org/pdf/2603.02641） |
| 4 | VAD | silero-vad 6.2.3 `get_speech_timestamps(..., threshold=0.5, min_speech_duration_ms=400, min_silence_duration_ms=300, speech_pad_ms=100, max_speech_duration_s=12)` | <1 GB | MIT、權重隨套件、離線（https://github.com/snakers4/silero-vad） |
| 5 | 主講者選取 | 每段切 1.5 s 視窗 → `speechbrain/spkrec-ecapa-voxceleb`（非 gated）或 3D-Speaker CAM++ `iic/speech_campplus_sv_zh-cn_16k-common`（中文訓練，較佳）→ `AgglomerativeClustering(metric='cosine', linkage='average', distance_threshold=0.45)` → 總時長最多的 cluster = 老師 | <1 GB | 若最大 cluster <60%（動畫角色劇雙角色）→ 兩個 profile 都保留，由 agent 選解說者。選配：pyannote community-1（下載需 HF token，之後離線）（https://huggingface.co/speechbrain/spkrec-ecapa-voxceleb ；https://github.com/modelscope/3D-Speaker ；https://huggingface.co/pyannote/speaker-diarization-community-1） |
| 6 | 組參考音檔 | 選 3–10 s、單人、殘留伴奏最低、無 clipping 的段落，以 200 ms 靜音串成 8–15 s（**<30 s 硬限**）；兩段 loudnorm（I=-18, TP=-2, LRA=7, `linear=true`，第二段必加 `-ar`）；輸出 `voices/ref_<case>.wav`（16 k）、`_24k.wav`（CosyVoice mel 路徑）、48 k 母帶 | 0 | -18 LUFS/-2 dBTP 是啟發式非官方規格（https://k.ylo.ph/2016/04/04/loudnorm.html） |
| 7 | 文字稿 | faster-whisper 載 `SoybeanMilk/faster-whisper-Breeze-ASR-25`（fp16，原生繁體；CV16-zh-TW WER 7.97 vs large-v3 8.95）`language='zh', beam_size=5, condition_on_previous_text=False` → `voices/ref_<case>.txt` + 全段 `work/transcript.json`（取代 look.py 的 CPU whisper） | ~4.5 GB（large-v2 數據，v3 UNVERIFIED） | 與 large-v3 結果 CER >0.15 → 標 low-confidence（壞 transcript 會悄悄毀掉 zero-shot）（https://huggingface.co/MediaTek-Research/Breeze-ASR-25 ；https://huggingface.co/SoybeanMilk/faster-whisper-Breeze-ASR-25） |
| 8 | 說話者輪廓 | parselmouth `to_pitch(60,500)` → F0 中位數/均值/95–5 百分位半音域；性別 dead-band（<155 男 / >185 女 / 其餘 uncertain）；語速 = CJK 字數 / VAD 語音秒；ECAPA 或 CAM++ embedding → `voices/ref_<case>.profile.json` | <1 GB | 最近 bank 聲音 = argmin `(1-cos) + 0.3·|log2(f0/bank_f0)| + 0.1·|rate−bank_rate|`（權重啟發式）（https://pypi.org/project/praat-parselmouth/） |
| 9 | 合成品管迴圈 | N=3 take（換 seed）→ 裁判 ASR → OpenCC s2twp + 去標點 + 數字轉中文 → `jiwer.cer` → CER ≤0.08 收；否則對錯字補注音/拼音 tag 再來 2 輪 | TTS 2–8 GB + 裁判 ASR 3–4.5 GB | 裁判**不可用 Breeze-ASR-25**（其訓練集 10,000 h 是 BreezyVoice 合成音，會對 BreezyVoice 錯音寬鬆）。裁判優先序：TEA-ASR-1（MIT、~4.2 GB、原生繁體、自評 CV19 zh-TW MER 3.64；單一作者自評）> Whisper large-v3 + OpenCC s2twp；可加 SenseVoiceSmall 第二裁判取 max CER（https://huggingface.co/JacobLinCool/TEA-ASR-1 ；https://huggingface.co/openai/whisper-large-v3 ；https://pypi.org/project/jiwer/） |

### VRAM 預算（24 GB）
- 前處理（2–8）串行，峰值 = Demucs 7 GB（或 3 GB）。
- 合成迴圈：TTS（BreezyVoice ~2–6 GB est. / CosyVoice3 ~5.2 GB）+ large-v3 fp16 ~4.5 GB 兩個 process 並存 <15 GB；若啟用更重引擎改 `compute_type='int8_float16'`（~3 GB）。
- torch 與 CTranslate2 各有自己的 caching allocator，跨 process 才會真的釋放；Demucs 絕不與 TTS 共駐。

## 3. Remotion 資料驅動渲染器設計

### 核心原則
**agent 只寫 `work/lesson.json`，從不寫 TSX**。Remotion 專案是固定、版本化的渲染器；「同原影片風格」這條軸由 `look.py` 產出的 `palette.json` + `style.form` 驅動 `buildTheme()` 達成，而不是 haidrrrry 的暗紫色 theme。姊妹專案「每支影片寫一個 TSX」的模式明確不採用（https://github.com/Jimmynycu/askback-skill）。既有 Pillow `render.py` 保留為 Chrome 無法啟動時的 fallback。

### 版本與執行環境
- 釘 **remotion 4.0.535**（2026-10-12）及 `@remotion/cli`、`@remotion/media`、`@remotion/fonts`、`@remotion/paths` 同版；Node 20/22 LTS（4.x 文件最低 16.0.0）；**不**上 5.0（未釋出）（https://github.com/remotion-dev/remotion/releases ；https://registry.npmjs.org/remotion/latest ；https://www.remotion.dev/docs/5-0-migration ；https://www.remotion.dev/docs/4-0-migration）。
- **Linux 無 root 取得 Chrome**：用 Remotion 自帶 Chrome Headless Shell，`npx remotion browser ensure` 下載到 `node_modules/.remotion/`（使用者目錄，無需 root——文件未明說，為推論）；預設 Headless Shell 模式，不用 `--chrome-mode=chrome-for-testing`（https://www.remotion.dev/docs/miscellaneous/chrome-headless-shell ；https://www.remotion.dev/docs/cli/browser/ensure）。
- 共用函式庫缺失時的無 root 路徑（依序嘗試）：(a) 系統已有；(b) micromamba/conda-forge 安裝 nss、libgbm、at-spi2-atk、alsa-lib、libcups 等 + `LD_LIBRARY_PATH=$CONDA_PREFIX/lib`（套件存在，端到端 **UNVERIFIED**）；(c) Debian/Ubuntu `apt-get download` + `dpkg-deb -x` 到 `~/.local` + `LD_LIBRARY_PATH`（rootless-playwright 模式）。失敗時 `--log=verbose`；慢或失敗才加 `--gl=swangle`（https://www.remotion.dev/docs/miscellaneous/linux-dependencies ；https://github.com/LooseChangeLabs/rootless-playwright ；https://anaconda.org/conda-forge/nss ；https://www.remotion.dev/docs/gl-options）。

### 資料契約
- `timing.json`（tts.py 以**實測** wav 長度產生）：`{fps, sample_rate, backend, voice, tail_s, total_s, narration, beats:[{id, scene, beat, file, start_s, dur_s, gap_s, cer}]}`。
- `palette.json`（look.py；現有 V03 的 palette.txt 是空檔，不可依賴）：`{bg, ink, accents[], dark, form_hint}`。
- lesson.json 既有 `{y|..}{g|..}{b|..}{r~|..}` 標記 → `theme.accent.*`，`~` → 刪除線/波浪線；由 `lib/markup.ts` 解析。

### 元件 API
```ts
type Props = { caseDir: string; lesson?: Lesson; timing?: Timing; palette?: Palette };
calc: CalculateMetadataFunction<Props> = async ({props, abortSignal}) => {
  // fetch(staticFile(`${caseDir}/lesson.json|timing.json|palette.json`)) → zod 驗證
  return { fps, durationInFrames: Math.ceil((timing.total_s + timing.tail_s) * fps), props: {...} };
};
<Composition id="AskBack" width={1280} height={720} fps={30} durationInFrames={1} calculateMetadata={calc} />
<ThemeProvider theme={buildTheme(lesson.style, palette)}>
  <Narration timing mode={lesson.style.audio ?? 'single'} />      // @remotion/media <Audio>
  <Series>{scenes.map(sc => <Series.Sequence durationInFrames={sceneFrames} premountFor={fps}><Form form={style.form} .../></Series.Sequence>)}</Series>
  <Captions beats subs /> <Badge text="AI 生成教學示範，非原講者本人" /> <Credit fromFrame={total-3*fps} />
</ThemeProvider>
```
Form 元件收 `beats:{startFrame,endFrame}[]`，每個 beat 的 `show` 放在 `<Sequence from layout="none">` 內持續存在直到 `{"clear":true}`。`calculateMetadata` 單次執行、與並行度無關，30 s 預設 timeout（https://www.remotion.dev/docs/calculate-metadata ；https://www.remotion.dev/docs/passing-props ；https://www.remotion.dev/docs/staticfile）。

### 四種 form 對應
| form | 來源風格 | 視覺 | 動態 |
|---|---|---|---|
| **board** | 電子黑板手寫 | bg=palette.bg(#000)、ink #f5f5f0、粉筆色取 palette.accents、字型 Iansui | `WriteOn`：`Intl.Segmenter('zh-Hant',{granularity:'grapheme'})` 逐字，`spring({delay:i*1.5, config:{damping:20,stiffness:120,mass:0.8,overshootClamping:true}})` 驅動 `clipPath: inset(0 (1-p)*100% 0 0)` + opacity；進場 14f、**無退場**；`DrawPath` 用 `evolvePath` + `getPointAtLength/getTangentAtLength` 畫箭頭 |
| **slides** | 投影片 | bg #fafafa、ink #1a1a1a、title bar=主 accent、Noto Sans TC | bullet `opacity+translateY(16px)`、`easing.out=bezier(0.16,1,0.3,1)`、進 18f / 退 8f / stagger 4f |
| **story** | 動畫角色劇 / 插畫圖卡 | bg=palette.bg、對話框 ink@92% | `Bubble` spring pop（scale .85→1 + opacity + translateY 12px，{d14,s160,m0.6}），左右交替，退 8f；角色允許 ±2 px sine 微動 |
| **lab** | 實驗實拍 / 真人+螢幕錄影 | bg=截圖 `<Img>`（**無** Ken Burns），標記色=與截圖均值對比最高的 accent | `Mark`（circle/arrow/label/polygon）stroke 6px、draw 20f；label fade+rise 12f |

### haidrrrry 十條規則：採用 / 捨棄
- **照用**：#1 禁 linear、spring 進場、`extrapolate clamp` 兩側（Remotion 預設 extend，必須明寫）；#8 所有時間由 `useVideoConfig().fps` 推算；#9 單一 theme 物件（= `buildTheme(form, palette)`）；#10 render → 抽幀 → 檢視 → 修 → 再 render（check.py 強制執行：每個 beat 首幀 + 末幀）；#4 退場快於進場（僅 slides/story）。
- **調整後採用**：#2「2–3 個屬性」→ slides/story/lab 標籤適用；board 只用 clip-wipe + opacity（粉筆不會縮放）。#3 stagger 3–6f → bullet/bubble/mark；逐字 write-on 1–2f。
- **捨棄（與「同原影片風格」衝突）**：#5 五層堆疊（gradient mesh/grade/grain/vignette/glow）——均一黑板與投影片是平面的；#6 每張靜圖 Ken Burns——lab 截圖必須與標記對位；#7 閒置元素呼吸——教學文字不可晃；「90 幀內必有新元素」→ 改為「每個 beat 的 show 在 `start_s` 後 10 幀內開始；字幕持續變化」。保留他的 out/inOut/in 三組 bezier，丟掉暗紫色 palette（https://raw.githubusercontent.com/haidrrrry/claude-remotion-skill/main/remotion-motion-graphics/SKILL.md ；https://raw.githubusercontent.com/haidrrrry/claude-remotion-skill/main/remotion-motion-graphics/assets/theme.ts）。

### 字型載入 API
`@remotion/fonts` 的 `loadFont({family, url: staticFile('fonts/Iansui-Regular.ttf'), weight})`，阻塞至載入完成；在 `src/fonts.ts` 呼叫三次、由 Root.tsx import；CSS 堆疊 `"Iansui","Noto Sans TC",sans-serif`（Iansui 僅覆蓋 Big5 約 8,170 字，必須有 Noto 兜底）。Iansui SIL OFL 1.1；Noto Sans TC license 頁面未成功抓取（預期 OFL，UNVERIFIED）（https://www.remotion.dev/docs/fonts-api/load-font ；https://github.com/ButTaiwan/iansui）。

### 音訊策略
- tts.py 同時輸出每 beat wav、串接的 `narration.wav` 與 `timing.json`。
- **預設**：單一 `<Audio src={staticFile('case/narration.wav')}>`（來自 `@remotion/media`，渲染時以 Mediabunny 精確抽音）掛在第 0 幀 → 零累積漂移、loudnorm 只跑一次。
- `style.audio="perBeat"` 切換：每 beat 在其 `<Sequence>` 內 `<Audio from={round(start_s*fps)}>`，每段 ≤1/fps（33 ms）誤差且不累積；好處是單 beat 重合成不用重串接。
- 字幕與 write-on 一律以 timing.json 對齊，不用估算時長。`<OffthreadVideo>` 不需要（素材皆為 PNG）（https://www.remotion.dev/docs/media/audio ；https://www.remotion.dev/docs/sequence）。

## 4. 風險與未驗證事項清單

**TTS**
1. 任何新模型對臺灣腔的保留強度皆 UNVERIFIED；零第一手「複製臺灣語者」回報；BreezyVoice 論文動機即是 CosyVoice 聽起來像大陸腔（https://arxiv.org/html/2501.17790v1）。
2. BreezyVoice 繼承的 WeTextProcessing 1.0.3 是否整句繁→簡 UNVERIFIED；G2PWModel-v2 學的是 PRC 還是臺灣教育部讀音（和/垃圾/企）UNVERIFIED。
3. CosyVoice3：維護者基本不回應（issue 多由 bot 於 44 天後關閉）；Fun-CosyVoice 3.5 已預告但未開源（#1840）；`llm.rl.pt` 載入靷 rename hack；transformers 4.51.3 死釘；VRAM 官方未列（3090 ~5.2 GB 為二手）。
4. CER 無法抓到的「電音」、開頭爆音（#1688/#1786）需另加 clipping/NaN/RMS 檢查；DNSMOS 選配。
5. BreezyVoice/CosyVoice3 參考音檔 ≤30 s；IndexTTS-2 靜默截到 15 s；F5 ~12 s——若未來換引擎要重看截取邏輯。
6. 降噪/分離對 speaker similarity 的量化影響無任何研究；0.85 cosine 門檻、-18 LUFS、0.45 聚類距離、155/185 Hz 性別帶、0.08 CER 門檻、bank 權重皆為啟發式，需在真實均一影片上調。
7. TEA-ASR-1 數字為單一作者自評、無發布日期；SoybeanMilk CT2 轉換與官方 transformers pipeline 精度是否一致 UNVERIFIED；faster-whisper large-v3 在 3090 的 VRAM/速度（只有 large-v2 於 3070 Ti 的數據）。
8. IndexTTS license 中英文門檻差 10 倍（1 億 vs 10 億），#228 無人回；DISCLAIMER 要求聲音授權——若採用需先取得老師/均一同意。
9. 3D-Speaker ModelScope 下載是否需登入 UNVERIFIED；silero-vad 6.2.3 是否仍有 numpy 未宣告依賴（PR #801 針對 6.2.2）。
10. Breeze-ASR-25 當裁判的偏誤（訓練集為 BreezyVoice 合成音）——已在設計上排除，但若 Whisper large-v3 對 zh-TW 幻覺嚴重，需回頭評估。

## 5. 對 SKILL.md 的具體修改建議

1. **硬體前提**：新增「執行本 skill 的 agent 預設擁有一張 NVIDIA RTX 3090（24 GB）；所有 ASR/TTS/分離/降噪一律在 GPU 上跑本地模型，不需 API key；禁止 CPU 推論 TTS（BreezyVoice #10 品質退化）」。
2. **流程改寫為五階段**：`look.py`（GPU：ffmpeg 截圖 + palette.json + Demucs/DFN3/silero/ECAPA/Breeze-ASR-25 → voices/ref_<case>.{wav,txt,profile.json} + work/transcript.json）→ agent 寫 `work/lesson.json`（契約不變，新增 `style.audio`、可選每詞讀音）→ `tts.py --backend`（best-of-N + 獨立裁判 CER → work/audio/*.wav、narration.wav、timing.json）→ `render.sh`（Remotion 4.0.535；失敗 fallback 到 Pillow render.py）→ `check.py`（抽幀檢視 + timing/CER 報表）。
3. **TTS 後端章節**：預設 `breezyvoice`；備援 `cosyvoice3`（列出前綴、fp16=False、OpenCC t2s、24 kHz 參考、transformers 4.51.3、llm.rl.pt rename 等護欄）；`edge` 僅在無 GPU 時作最後 fallback。明列「切換到非 BreezyVoice 引擎的採用門檻：3 位老師音檔 A/B，重試率 ≤30%、CER ≤0.08、臺灣母語者盲聽不判為大陸腔」。
4. **聲音契約**：`voices/<name>.wav`（16 kHz mono、6–15 s、<30 s、無 BGM、loudnorm 後）+ `voices/<name>.txt`（繁體逐字稿，與音檔完全吻合）+ `voices/<name>.profile.json`；由 look.py 自動產出每案例參考音檔，bank 聲音以 profile 最近鄰選取；參考音檔需取得老師/均一授權後才可用於公開影片，且影片每一幀保留「AI 生成教學示範，非原講者本人」標示。
